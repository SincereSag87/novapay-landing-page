# NovaPay Landing Page

NovaPay is a fictional premium fintech landing page created for a frontend, UI, and UX portfolio. The concept presents a modern digital banking and payments platform for people who spend, save, send, and manage money across borders.

## Product Concept

NovaPay gives digitally native consumers one modern account for everyday spending, virtual and physical cards, instant transfers, spending insights, savings goals, subscription awareness, security controls, and international money movement.

## Target Audience

- Young professionals
- Freelancers
- Remote workers
- Creators
- Internationally mobile consumers
- People who manage income, spending, and payments across currencies

## Design Direction

The visual direction is premium, restrained, editorial, and finance-focused. The page uses a near-black primary surface, warm white backgrounds, soft slate neutrals, electric blue, cyan, and teal accents. The experience is composed around mobile product visuals, card controls, cinematic spacing, strong typography, and high-contrast financial UI details.

## Differentiation From LaunchKit

NovaPay intentionally avoids LaunchKit's bright startup SaaS tone, card-heavy dashboard layout, violet palette, and productivity-focused composition. This page uses mobile-device product storytelling, darker fintech surfaces, asymmetrical sections, fewer repeated cards, stronger negative space, and a more cinematic financial brand rhythm.

## UX Goals

- Communicate what NovaPay is within the first viewport
- Make the account-opening CTA visible and clear
- Establish trust without fake bank logos or unsupported insurance claims
- Show product capability through believable mobile UI
- Keep the page responsive across desktop, tablet, and mobile viewports
- Maintain strong contrast, accessible navigation, and keyboard focus states

## Features

- Responsive navigation with accessible mobile menu
- Premium hero with mobile banking app mockup
- Trust and security messaging
- Spending insights and transaction feed composition
- Physical and virtual card showcase
- International transfer preview
- Savings goal product story
- Security controls section
- Fictional user testimonials
- Immersive app finale
- Full-width final CTA

## Tech Stack

- React
- Vite
- JavaScript
- Modern CSS

## Responsive Design

The layout is designed and tested for:

- 1440px desktop
- 1024px desktop/tablet
- 956x440 landscape
- 768px tablet
- 440x956 mobile
- 390px mobile

Complex product visuals simplify on smaller screens while preserving strong typography, comfortable tap targets, and no horizontal overflow.

## Accessibility

- Semantic HTML structure
- Logical heading order
- Keyboard-accessible navigation and controls
- Visible focus states
- Sufficient color contrast
- Accessible mobile menu state
- Reduced-motion support
- Text remains readable instead of being embedded only in decorative imagery
